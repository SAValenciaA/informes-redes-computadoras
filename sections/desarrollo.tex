\section{Desarrollo}

Se explicara el procedimiento desarrollado para realizar el laboratorio 4: spanning
tree protocol. Este fue hecho utilizando los switches Catalyst 2960 de la marca Cisco
para diferenciar los protocolos Per VLAN Spannning Tree Protocol (PVSTP) y Rapid
Spanning Tree Protocol (RSTP). Ambos protocolos fueron probados usando la misma
topologia que se muestra en la figura \ref{fig:topology}.

conexiones en la Table \ref{tab:conn}.
